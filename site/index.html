🧠 Mandu (`mandu`)

Ambiente soberano de escrita acadêmica, gestão de conhecimento e publicação científica em 100% Rust integrado ao motor Joaju.

GOST v1.1.0 Perfil: lumen.md 100% Rust Apache-2.0 HedgeDoc-Style

Pilares Arquiteturais

1. Padrão HedgeDoc

Separação estrita entre escrita monoespaçada e painel sincronizado de leitura. Fim do live preview instável.

2. Pipeline Único (Joaju)

Renderização idêntica na tela e no PDF final via Typst e motores científicos (ABNT NBR 14724, trabalho-ufsc e Vancouver).

3. Core Desacoplado

SQLite in-memory (FTS5), scanner paralelo em <30ms e cache BLAKE3 isolados em mandu-core.

4. Multi-View Nativo

Cascas finas: mandu-tui (Ratatui para Debian/Termux) e mandu-gui (egui GPU nativo e Android).

Como Iniciar

# Clonar o repositório
git clone ssh://git@codeberg.org/lumenpink/mandu.git
cd mandu

# Auditoria GOST estrita
cccp check --strict

# Executar suíte de testes
cargo test

# Executar a interface TUI
cargo run -p mandu-tui

# Executar a interface gráfica GPU
cargo run -p mandu-gui
