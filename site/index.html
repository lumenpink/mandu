Feito para Pensar e Estudar

Foco na Escrita

Separação clara entre a área de redação e o painel de leitura, proporcionando um ambiente tranquilo e livre de distrações.

Seus Textos Sempre com Você

Suas notas são salvas diretamente no seu dispositivo em arquivos locais, sem prender seus dados a serviços proprietários.

Organização e Busca Rápida

Encontre anotações, rascunhos e referências cruzadas instantaneamente com indexação local veloz.

Multiplataforma Confortável

Disponível como aplicativo visual para desktop, interface no terminal e aplicativo para dispositivos móveis.

Como Iniciar

Você pode compilar o Mandu diretamente do código-fonte ou baixar as versões pré-compiladas na Banca 2LP:

# Clonar o repositório oficial
git clone https://gambi.2lp.in/lumen/mandu.git
cd mandu

# Executar a interface no terminal
cargo run -p mandu-tui

# Executar a interface visual no desktop
cargo run -p mandu-gui

Atalhos Essenciais

O Mandu foi desenhado para manter o fluxo contínuo de pensamento com comandos rápidos:

Atalho Ação Descrição
Ctrl + N Nova Nota Cria uma nova nota rapidamente no caderno ativo.
Ctrl + S Salvar Grava as alterações imediatamente em disco.
Ctrl + P Alternar Visualização Alterna entre o modo de edição e a prévia do documento.
Ctrl + F Buscar Pesquisa notas em todo o caderno instantaneamente.
Ctrl + Q Sair Fecha a sessão de edição com segurança.
