🧠 Mandu (`mandu`)

Seu bloco de notas e caderno pessoal seguro para organizar pensamentos, estudos e ideias do dia a dia, com visual limpo e privacidade total.

Caderno Pessoal Bloco de Notas Privacidade Total Foco na Escrita Sem Nuvem Obrigatória Software Livre

Feito para Pensar e Estudar

1. Foco na Escrita

Separação clara entre o espaço para redigir suas anotações e a visualização limpa do texto formatado.

2. Seus Textos Sempre com Você

Tudo fica salvo direto no seu computador ou celular em arquivos locais fáceis de abrir, sem te prender a serviços fechados.

3. Organização e Busca Rápida

Localize qualquer anotação, ideia ou rascunho em milissegundos sem complicação.

4. No Terminal, no Computador ou no Celular

Versões leves para aplicativo gráfico no desktop, terminal ou aplicativo para Android.

Como Iniciar

# Clonar o repositório
git clone https://git.2lp.in/lumen/mandu.git
cd mandu

# Executar a interface no terminal
cargo run -p mandu-tui

# Executar a interface gráfica no desktop
cargo run -p mandu-gui
